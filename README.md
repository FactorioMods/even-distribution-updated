# Even Distribution: Updated

Factorio 2.1 update of Even Distribution. Original author: 321freddy. Modifies CTRL + Click Drag to evenly distribute the items over multiple buildings. 

Adds Inventory Cleanup hotkey (SHIFT+C) to evenly distribute uneeded items from your inventory into nearby machines.

Disable the original mod before enabling this fork. Entity, item, recipe and startup setting names are retained. Mod-private runtime state belongs to the old mod identity; per-player transient UI/distribution state is rebuilt.
