# Even Distribution: Updated

Distribute items evenly between machines with Ctrl+click-drag. Shift+C distributes unwanted inventory items to nearby machines.

**Factorio 2.1 · Version 1.0.3**

- Balance existing contents or distribute a new stack.
- Supports fuel replacement and half-stack distribution.

## Installation

Disable even-distribution before enabling this fork. Pending drags are cancelled when a player disconnects; the items stay with the player.
